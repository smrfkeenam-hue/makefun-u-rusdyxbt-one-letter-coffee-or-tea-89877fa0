# AGENT.md

Entry for make.fun's "One Letter: Coffee or Tea" bounty: a Python 3.13
standard-library program that writes exactly one character, "A" (coffee),
to `/output/entry.txt` with no trailing newline. The letter was chosen as
the livelier, more vivid stance for the judge's vivid/funny/true criteria.
Built fresh in this session from the kit's RULES.txt and competition.yaml:
main.py was written, then revised twice (output-path helper, then a
choice mapping with a main() entry point), keeping the output byte-identical
throughout; README.md carries all three make.fun badges including reward.svg.
